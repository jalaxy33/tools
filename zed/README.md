# 我的zed设置

[Zed](https://zed.dev/) 是一个类似于 vscode 的编辑器，由 rust 开发，性能很好。

## 插件

zed 内置了很多好用的插件，基本上开箱即用。在右上角菜单里选择 `extensions` 可以搜索和安装插件。

- 图标：`Colored Zed Icons Theme`
- 主题：`Github Theme`
- 查看依赖版本是否最新：`Dependi`
